---
name: Journey map-first experience
description: Product intent for the map-first world, day-contained memories, and final-island personal rewards.
---

The primary memory experience is Journey → Day → Memory. A saved day's optional photo/caption belongs in its day detail, with a small indicator on the exact map node. Home/history/recap entries should return to that verified day. The gallery is secondary history, not a standalone photo product.

**Why:** The user explicitly corrected the product experience to make memories part of each journey day's story.

**How to apply:** Reuse the day-linked memory flow when adding new surfaces. Never require capture for success, XP, coins, or progression; upload failure and deletion must leave those intact. Keep sharing explicit and private by default. Preserve ambiguous old memories as unlinked history rather than inventing day destinations.

Journey is a map-first world, not a dashboard with a small map. Retain the existing islands, path and character; keep day details on demand, with a mobile sheet and minimal fullscreen controls. Personal rewards belong to the final island and open within the map. The user removed the independent coin-priced rewards section; do not reintroduce it.

**Why:** The user supplied a map-first rebuild specification and explicitly asked to keep only journey rewards. This is a product direction, not permission to erase historical financial data.

**How to apply:** Future journey additions must support the map rather than reserve permanent dashboard columns. Preserve stored legacy rewards and transactions; personal reward claims must not spend coins.
