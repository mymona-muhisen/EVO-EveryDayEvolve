---
name: Legacy memory association
description: Why pre-feature memories must remain explicitly unlinked rather than matched to current journey dates
---

Do not infer saved journey-day associations for old memories from habit and date alone. Preserve their full notes and photos, including notes longer than the new caption limit; shortening requires an explicit user edit.

**Why:** The earlier feature allowed standalone notes and ambiguous habit/date references. Those values do not prove which immutable journey day, if any, the user intended.

**How to apply:** Keep uncertain historical associations unset during migrations and compatibility changes. Enforce the stricter completed-day relationship for new records without rewriting old history.
